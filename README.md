# Primitive Ignition: Crafting

Minecraft 1.21.11 + Fabric add-on for Survivalist Essentials.

## Included in the current source
- Registers one new item: `primitive_ignition_crafting:primitive_flint`.
- Adds it to the Tools creative tab.
- Adds a shaped recipe using vanilla flint plus `survivalistessentials:plant_fiber` and `survivalistessentials:plant_string`.
- Adds English and Russian item names and a temporary vanilla-flint visual.
- Does not change furnace behavior. That belongs to the separate Realistic Ignition project.

## Status
The item, recipe, and basic resources are present in source. The project has not yet been compiled or tested in Minecraft, and the temporary icon still needs a dedicated texture. Do not treat it as a verified working JAR.
